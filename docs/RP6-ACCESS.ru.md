# Постоянный SSH-доступ к RP6

Доступ включается только при явном добавлении открытого ключа владельцем.
Закрытый ключ и пароль в скрипт или образ не включаются. Вход — под `steamos`;
настройки sudo и существующие ключи пользователя сохраняются.

На текущей приставке скачайте `rp6-codex-access.sh` и запустите в Konsole:

```bash
bash ~/Downloads/rp6-codex-access.sh
```

Установщик сравнивает отпечаток SSH-сервера с указанным при сборке,
настраивает `rp6-steamos.local`, автоподключение текущего Wi-Fi и SSH.
Имя `.local` доступно в той же локальной сети при работающем Avahi.
Служба `rp6-codex-access` устанавливает ключ при загрузке;
таймер проверяет ключ и состояние SSH раз в минуту, в том числе после
пробуждения. Рабочее соединение Wi-Fi принудительно не перезапускается.
При наличии ключа в новом чистом образе настройка выполняется при первом
запуске. Новый серверный ключ после чистой установки проверяется отдельно
на самой приставке; клиент не отключает проверку подлинности сервера.

Постоянный журнал ограничен 96 MiB, оперативный — 32 MiB. Подробная
диагностика UP-04 сохраняется включённой после приёмки. Проверка:

```bash
systemctl status rp6-codex-access.timer sshd.service
journalctl -u rp6-codex-access.service -b
```

Для отзыва именно этого доступа отключите службу и таймер, удалите
`/usr/share/steamos-arm/access/codex.pub` и соответствующую строку
из `/home/steamos/.ssh/authorized_keys`. Остальные ключи не удаляйте.
Разблокировка `/usr` установщиком временная: исходное состояние
«только чтение» восстанавливается при выходе.

Сборка установщика: `scripts/build-rp6-access-installer.py` принимает
открытый ключ, проверенный отпечаток сервера и путь выходного файла.
Образ принимает тот же открытый ключ как отдельный вход рецепта с SHA256;
скрытые пользовательские файлы в запечатанном HOME при сборке не меняются.
